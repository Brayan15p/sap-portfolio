# Mm Grir Clearing Analyzer

**Area:** MM/FI · GR/IR clearing

## Problem and solution

Problem: the GR/IR account grows every month and auditors ask why. Per PO line it classifies the difference: goods received not invoiced, invoiced not received, price difference; ages it and proposes the clearing action.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Parameters are illustrative.
