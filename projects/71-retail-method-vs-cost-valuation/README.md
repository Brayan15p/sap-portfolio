# Retail Method Vs Cost Valuation

**Area:** IS-Retail · Inventory valuation (Lidl case)

## Problem and solution

Problem (Lidl, ~€500M): Lidl valued inventory at purchase price while SAP retail is built around retail price; instead of adapting the process they customized SAP heavily. This shows both methods side by side: the retail inventory method (cost-to-retail ratio) vs actual purchase cost, and the gap per category.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Parameters are illustrative.
