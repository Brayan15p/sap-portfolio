# Retail Promo Replenishment

**Area:** IS-Retail · Store replenishment with promotions

## Problem and solution

Problem: stores run out during promotions because replenishment uses normal demand. Forecasts with a promotion uplift, nets store stock and in-transit, rounds to the case pack and caps by shelf capacity.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Parameters are illustrative.
