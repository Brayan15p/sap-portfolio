# Mm Obsolete Stock Provision

**Area:** MM/FI · Slow-moving and obsolete stock

## Problem and solution

Problem: auditors require a provision for stock that does not move. Classifies stock by days since last consumption and expiry, applies the provision policy per bucket and produces the provision entry.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Parameters are illustrative.
