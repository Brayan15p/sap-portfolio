# Wm Slotting By Velocity

**Area:** EWM/WM · Warehouse slotting

## Problem and solution

Problem: pickers walk kilometers because fast movers sit at the back. Ranks SKUs by picks per cubic meter and assigns the closest bins to the fastest movers, reporting the expected walking distance saved.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Parameters are illustrative.
