# Ai Cash Application Remittance

**Area:** AI · Cash application

## Problem and solution

Innovation: a customer pays one lump sum for several invoices with a messy remittance note. Finds the combination of open invoices that sums exactly to the payment (subset sum), preferring invoices mentioned in the note.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
