# Esg Purchase Carbon Footprint

**Area:** ESG · Scope 3 emissions (Sustainability Footprint)

## Problem and solution

Innovation/trend: CSRD and buyers ask for Scope 3. Estimates CO2e of purchases with spend-based factors (and activity-based where quantity is known), aggregates by supplier and category and shows which suppliers drive 80% of emissions.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
