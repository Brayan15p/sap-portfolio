# Fin Dynamic Discounting

**Area:** Treasury · Dynamic discounting / supply chain finance

## Problem and solution

Innovation: suppliers want cash early; the buyer has idle cash earning little. Computes the annualized return of paying early for a discount, offers a sliding discount by days accelerated, and selects invoices that beat the company's hurdle rate within available cash.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
