# Supplier Risk Scoring

**Area:** Procurement · Supplier risk

## Problem and solution

Problem (2020-2022 supply crisis): single-sourced critical materials from risky suppliers stop plants. Scores each supplier by country risk, single-source dependency, on-time performance and financial signal, and lists critical materials without an alternative source.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
