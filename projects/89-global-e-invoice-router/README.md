# Global E Invoice Router

**Area:** Global compliance · E-invoicing

## Problem and solution

Innovation: a multinational on one SAP must issue invoices in each country's mandated format and channel. Routes each invoice to the right format, channel and clearance model, and validates the country-specific mandatory fields before sending.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
