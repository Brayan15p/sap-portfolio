# Ps Earned Value

**Area:** SAP PS · Project control (EVM)

## Problem and solution

Real case: a hospital construction project is 'on budget' until it suddenly isn't. Earned value management computes PV, EV, AC, CPI, SPI, estimate at completion and variance at completion per WBS element, and flags elements trending over budget.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
