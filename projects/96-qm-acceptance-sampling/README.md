# Qm Acceptance Sampling

**Area:** SAP QM · Inspection lots

## Problem and solution

Real case: hospital supplies are inspected on receipt by sampling. Given lot size, sample size n and acceptance number c, decides accept/reject and computes the probability of accepting a lot with a given defect rate (OC curve, binomial).

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
