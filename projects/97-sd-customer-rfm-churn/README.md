# Sd Customer Rfm Churn

**Area:** SD / CX · Customer analytics

## Problem and solution

Innovation: a distributor loses customers silently. RFM (recency, frequency, monetary) quintile scoring segments customers and flags 'at risk' (were good, stopped buying) so sales calls them before they leave.

## Run

```bash
pytest -q
```

Python 3.11+, standard library only. Factors and thresholds are illustrative.
